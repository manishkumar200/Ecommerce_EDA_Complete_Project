
# AI-Powered EDA & Statistical Storytelling
### Mini Project | Indian E-commerce Analytics

## Project Overview
This project analyzes Indian e-commerce order data using Python, Exploratory Data Analysis (EDA), statistical reasoning, anomaly detection, and AI-assisted interpretation.

The objective is to transform raw data into meaningful business insights and actionable recommendations that support data-driven decision-making.

## Business Problem
E-commerce businesses need to understand customer purchasing behavior, sales performance, marketing effectiveness, delivery experience, and unusual order patterns to improve business outcomes.

This project uses data analysis and statistical techniques to investigate these areas.

## Project Objectives
- Perform data quality assessment and data cleaning.
- Conduct Exploratory Data Analysis (EDA).
- Apply descriptive statistics and statistical reasoning.
- Identify anomalies and unusual order patterns.
- Explore relationships between business variables.
- Use AI-assisted interpretation to communicate findings.
- Develop data-driven business recommendations.

## Dataset
**File:** `AI_Powered_Ecomerce_EDA_Project_Dataset.csv`

- Raw records: 1,201 rows
- Contains one intentional duplicate
- Includes missing values and outliers for practice
- Domain: Indian E-commerce Analytics

## Business Questions
1. Which categories, cities, and customer types generate the most value?
2. Which customer group has the highest average order value?
3. Which marketing channels appear strongest?
4. Is delivery experience associated with customer satisfaction?
5. Which variables are correlated with order amount?
6. Which orders appear anomalous?
7. What actions should management consider?

## Project Workflow

### 1. Data Quality Assessment
- Inspect dataset shape and data types.
- Identify missing values and duplicate records.
- Detect inconsistent and suspicious values.
- Review numeric distributions and outliers.

### 2. Data Cleaning
- Handle missing values using suitable techniques.
- Remove or investigate duplicate records.
- Validate data types and categorical values.
- Flag suspicious values for further analysis.

### 3. Exploratory Data Analysis
- Univariate analysis of important variables.
- Bivariate analysis of customer and order attributes.
- Category-wise and city-wise order analysis.
- Customer segmentation and purchasing behavior.
- Data visualization using Matplotlib and Seaborn.

### 4. Statistical Analysis
- Mean, median, mode, standard deviation and quartiles.
- Distribution and variability analysis.
- Correlation analysis.
- Statistical comparisons between customer groups.
- Hypothesis testing, where appropriate.

### 5. Anomaly Detection
- Identify unusual order amounts.
- Investigate extreme values and potential outliers.
- Apply IQR or other suitable methods.
- Distinguish possible data errors from legitimate unusual orders.

### 6. AI-Assisted Statistical Storytelling
- Convert analytical findings into understandable explanations.
- Generate potential interpretations of observed patterns.
- Validate AI-generated explanations against actual data.
- Summarize insights for business stakeholders.
